# 能量與簡單機械

供理化老師示範功、動能與位能、彈簧、擺錘及簡單機械的互動教具（第35版）。

網站：https://hikaruhen.github.io/energy/

## 使用

選擇主題及實驗，直接拖曳物件與箭頭調整。按計算後即時更新；比較動能的「計算並演示」會啟動同步動畫。支援播放、暫停、單步、重播；切換實驗保留狀態，重新整理會重設。

槓桿支援兩側配置及同側長／短施力臂。輪軸可比較固定3m拉繩行程或相同提升高度。滑輪可拖取擴充，擺錘及彈簧可停在關鍵位置。

## 驗證與限制

31項物理、圖形及邊界測試通過。以瀏覽器模擬檢查375×667、390×844、667×375、844×390、1024×768與1366×768，尚未實體手機或平板驗收。

機械為忽略摩擦、繩與滑輪重量及慣性的準靜態模型；不模擬碰撞。圖形為教學示意，各實驗明示力比例尺，箭身表示大小、固定箭頭表示方向。
